## Reviewer workflow

- Open or download the saved submission material and locate the appropriate report.
- Check the report's exact fixture ID and its final marker.
- Enter comments clearly prefixed with `QA TEST ONLY`.
- Use test scores solely to exercise the configured rubric, not to represent a mathematical assessment.
- Save a draft, reload it, and confirm that all fields persist.
- When authorized in the test competition, submit the review and verify its status.

Both reports are included in the same repository. Select the report matching the team's chosen problem. Submit a full 40-character commit hash so the platform saves a fixed version.
